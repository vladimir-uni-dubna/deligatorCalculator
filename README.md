# DelegatorCalculator

WPF калькулятор с использованием делегатов и событий в C# (.NET Framework 4.7.2).

## Что здесь происходит

### Делегаты
- `MathOperation` — делегат для математических операций (принимает два double, возвращает double)
- Позволяет передавать методы как параметры в `Calculator.Execute()`

### События
- `CalculationPerformed` — событие, которое срабатывает после каждого вычисления
- Использует делегат `CalculationEventHandler`
- Передаёт информацию через `CalculationEventArgs` (операнды, результат, название операции)

### Как это работает
1. Окно создаёт экземпляр `Calculator`
2. Подписывается на событие `CalculationPerformed` через `+=`
3. При нажатии кнопки операции сохраняется первый операнд
4. При нажатии "=" вызывается `Calculator.Execute()` с соответствующим делегатом
5. После вычисления автоматически срабатывает событие
6. Обработчик события выводит информацию в консоль (можно расширить)

## Структура проекта

- **Calculator.cs** — класс с делегатами и событиями
- **MainWindow.xaml** — разметка интерфейса WPF
- **MainWindow.xaml.cs** — логика окна и обработчики
- **App.xaml** / **App.xaml.cs** — точка входа приложения

## Запуск

Открыть `deligatorCalculator.sln` в Visual Studio и запустить (F5).

## Интерфейс

- Дисплей для отображения чисел и результата
- Кнопки с цифрами 0-9
- Кнопка десятичной точки (.)
- Четыре кнопки операций: +, -, ×, ÷
- Кнопка очистки (C)
- Кнопка равно (=) на всю ширину

## Ключевые моменты

- **Делегат** = тип, который хранит ссылку на метод
- **Событие** = механизм уведомления подписчиков (паттерн Observer)
- `event` делает делегат безопасным (подписчики не могут вызывать событие напрямую)
- `?.Invoke()` — безопасный вызов (проверка на null)
- `+=` — подписка на событие
- `-=` — отписка от события
- WPF использует XAML для описания интерфейса
